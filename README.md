# Learn Business Cases & ROI with Phoebe

A case a finance team will sign, in ten 45-minute sessions on two tracks.

- **Leader (b1-b4, no code):** what a business case is for, reading a case like a CFO, the
  assumption doing the work, and what happens after the yes.
- **Analyst (a1-a6, hands-on in the browser):** only the cash that changes, time value and the
  hurdle rate, NPV, IRR and payback, swinging every assumption, the range and the option to wait,
  and the business case bench.

Every widget runs one engine in the browser (`assets/bcr-live.js`): cash flows, NPV, IRR,
paybacks, a tornado with switching values and 5,000 seeded draws. An independent Python build
(`materials/bcr_reference.py`) prints the same numbers. The running case, Keelson Mutual's claims
fast-track triage, is constructed. Sources: HM Treasury's Green Book (2026) and its supplementary
guidance, Aswath Damodaran's corporate finance notes, Flyvbjerg and Budzier (2011).

Static site: open `index.html`, or serve the folder with `python3 -m http.server`.
